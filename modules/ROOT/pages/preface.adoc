== Preface

*_Preface to Version 20250616_*

Clarifications only - no changes to normative behaviour.

* Updated xref:payload.adoc#packets[Instruction Trace Encoder Output Packets] and xref:fragmentCodeAndTransport.adoc#fragments[Code fragment and transport] to reference the https://github.com/riscv-non-isa/e-trace-encap/releases/latest/[Unformatted Trace & Diagnostic Data Packet Encapsulation for RISC-V Specification];
* Removed ambiguity between 'last' and 'final'.  Last was previously used to mean both the instruction before the current one, and the final instruction traced;
* Clarified behaviour when trace-on and trace-off triggers occur both occur in the same cycle (see xref:ingressPort.adoc#sec:trigger[Using trigger outputs from the Debug Module]);
* Clarified that full synchronization also takes place on a privilege change (see xref:branchTrace.adoc#sec:synchronization[Synchronization] and xref:payload.adoc#sec:thaddr[Format 3 thaddr, address and privilege fields]);
* Reworded jump classifications in jump classifications in xref:ingressPort.adoc#sec:InstructionInterfaceRequirements[Instruction Trace Interface requirements] to align with terminology used in other specifications;
* Clarified when to issue sync-support packet when trace is enabled (see xref:payload.adoc#sec:format33[Format 3 subformat 3 - Support]);
* Clarified that branch_map can be set to 31 any time an address needs to be reported and the branch map is full (see xref:payload.adoc#sec:format1[Format 1 packets]);
* Updated reference encoding algorithm to generalize resync behaviour and add missing trap conditions (see xref:exampleAlgorithm.adoc#Algorithm[Reference Compressed Branch Trace Algorithm]);
* Clarified that implicit returns are not stored in the jump target cache (see xref:branchTrace.adoc#sec:jump-cache[Jump target cache mode]);
* Updated decoder to remove ECALL, EBREAK and C.EBREAK from is_uninferrable_jump function.  Including them is harmless but unnecessary, as these instrucitons don't retire (see xref:decoder.adoc#Decoder[Decoder]);
* Corrected description of why the EPC is not always reported (see xref:payload.adoc#sec:thaddr[Format 3 thaddr, address and privilege fields]).
* Minor clarifications, formatting and typo fixes.
